# Bloc à coller sur mcj-courtage.com

> Préparé le 14/10/2026 (chantier autorité, action « liens » n°1). mcj-courtage.com appartient au propriétaire :
> c'est le lien le plus rapide à obtenir. Aujourd'hui ce site ne fait que 2 liens vers tempo-assurance.com.

## Où le mettre

Dans le **corps** de la page d'accueil de mcj-courtage.com, ou d'une page « Nos marques » / « Nos offres ». Pas
seulement dans le pied de page : Google accorde plus de poids à un lien placé dans un texte qui parle du sujet.

```html
<section>

  <p>MCJ Courtage propose l'<a href="https://www.tempo-assurance.com/">assurance auto temporaire en ligne</a> sous la

  le paiement.</p>
  <p>La même souscription couvre aussi l'<a href="https://www.tempo-assurance.com/assurance-temporaire-camion.html">assurance

  et l'<a href="https://www.tempo-assurance.com/assurance-temporaire-frontiere.html">assurance frontière</a> pour les
  véhicules immatriculés à l'étranger.</p>
</section>
```

## Règles

- Les liens doivent être des liens normaux : **pas de `rel="nofollow"`**, pas de redirection.
- Ne pas recopier ce texte ailleurs mot pour mot : un même bloc sur plusieurs sites ressemble à un lien fabriqué.
- Vérifier une fois en ligne : clic sur chaque lien, la page Tempo s'ouvre.
